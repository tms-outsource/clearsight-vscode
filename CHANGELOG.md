# Changelog

## 0.1.0

First release.

- Three variants: Clearsight (dark), Clearsight Soft and Clearsight Light, each with a No Italics version.
- Every syntax color, comments included, passes WCAG AA (4.5:1) on the editor background and the current line.
- Token pairs stay distinguishable under protanopia, deuteranopia and tritanopia simulations.
- Full workbench coverage: editor, terminal ANSI colors, Git and diff, bracket pairs, inline suggestions, chat, notebooks, debugging and testing.
- Semantic highlighting enabled.
